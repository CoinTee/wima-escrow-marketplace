# Wima Escrow Marketplace

A polished concept demo for a trust-first marketplace and escrow product. This is a static front-end prototype designed for early user testing, investor storytelling, and pre-seed demo presentations.

## What this prototype demonstrates
- Buyer and seller flows
- KYC / verification onboarding
- Listings and receipt filters
- Escrow locking and trusted meetup flow
- QR-code identification checks
- Delivery risk handling
- Admin review and dispute controls
- Safety explanations and risk language

## Important note
This is a demo product prototype for concept validation. It is not a live financial platform and does not handle real money, real identity verification, or actual escrow settlement.

## Local preview
Open `index.html` directly in a browser, or serve the folder with any static server.

Example:

```bash
python3 -m http.server 8000
```

Then open:

http://localhost:8000
